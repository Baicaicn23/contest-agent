# 切换模型与控制预算（How-to）

## 切换模型

**界面**：输入卡右下角模型名 ▾（或 设置 → 模型档案），选择即写回 config.yaml，CLI 同步生效。

**CLI**：

```bash
uv run sai model list          # 看全部档案
uv run sai model use qwen      # 切到 qwen 档案
```

**临时实验**（不改配置）：`ACTIVE_MODEL=qwen uv run sai identify`

新增档案：在 config.yaml `models` 段加一组（base_url/api_key_env/model/单价），
密钥写进 `.env` 对应的环境变量。

## 按任务路由（省钱的关键）

高频任务配便宜模型、重活配强模型：

```yaml
routing:
  identify: deepseek    # 高频识别用便宜快速的
  generate: deepseek    # 材料生成是重活
  chat: deepseek
```

没列出的任务用 `active_model` 兜底。花没花对地方用 `uv run sai cost` 按任务查证。

## 预算熔断

```yaml
budget_per_task_yuan: 5   # 一次任务的花费上限
# 临时实验：BUDGET_PER_TASK_YUAN=0.001 uv run sai identify
```

熔断语义：达线的**下一笔调用发出前**被拦（不是事后报警）；
已完成的部分（已入库卡片、已落盘大纲）保留。
