# 使用三档权限（How-to）

> 三档权限控制 agent 的工具能"动"到什么程度。入口：输入卡左下的盾牌下拉（或 设置 → 权限）。

## 三档语义

| 档位 | 网页聊天 | 终端 sai | cron/watch |
| --- | --- | --- | --- |
| **只读** | 写类工具一律拒绝 | 同左 | 同左（全局生效） |
| **变更前确认**（默认） | 写类工具被拦（无法弹窗确认，拒绝理由会引导你） | 名单内工具执行前 y/N | 由 unattended_deny_tools 名单控制 |
| **完全访问** | 全放行 | 全放行 | 全放行 |

写类工具 = 会改动系统状态的三件：扫官网入库（scan）、识别入库（identify）、
保存材料（save_material）。查卡片/读通知/搜索/查截止这些读类工具任何档位都可用。

## 典型场景

- **日常浏览查询** → 只读。随便问，agent 碰不到你的数据；
- **想让 agent 干活但怕它乱来** → 变更前确认 + 终端里用 sai（可以逐次 y/N）；
- **明确要它办事**（"帮我扫官网"）→ 完全访问，办完切回来。

## 被拦了是什么样

只读档下发"扫一下官网"，agent 会如实回复"被权限门拦住了，当前是只读模式"，
并主动给出替代方案（比如先查库里已有的比赛、查临近截止）。拒绝原因对模型可见，
它不会瞎编扫描结果。
