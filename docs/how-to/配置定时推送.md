# 配置定时推送（How-to）

> 目标：让系统每天自动盯官网，新比赛/临近截止自动推给你。

## 前置：选一个推送通道

在 `config.yaml` 的 `push` 段配置（三通道独立，配了即启用）：

**Webhook（钉钉/企微/Server酱）**——最推荐，五分钟搞定：

```yaml
push:
  webhook_url: https://oapi.dingtalk.com/robot/send?access_token=xxx
```

**文件落盘**（调试利器，通知写成 Markdown）：

```yaml
push:
  file_dir: output/notifications
```

**邮件**：需要 SMTP 授权码（`smtp.host/port/user/to_addrs` + 环境变量 `SMTP_PASSWORD`）。

## 手动验证一轮

```bash
uv run sai watch
```

一轮做三件事：扫官网 → 识别新比赛 → 推送 + 截止警报。
去你的钉钉群（或 output/notifications/）确认收到了。

## 接入 cron 定时

```bash
crontab -e
# 每 30 分钟盯一轮（8:00-22:00 之间）
*/30 8-22 * * * cd /你的项目路径/contest-agent && uv run sai watch >> /tmp/watch.log 2>&1
```

## 行为细节

- 识别结论有记忆缓存：同一通知不会重复识别、重复推送；
- 截止警报四档（T-7/3/1/0 天），同档不重吵，窗口内晚添加会补发；
- 至少一个推送通道送达才记账，全挂下轮重试；
- cron 场景属"无人值守"：`permissions.unattended_deny_tools` 名单里的工具会被拦。
