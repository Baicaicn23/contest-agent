# 跑识别评测防退化（How-to）

> 目标：改了识别提示词/模型/路由之后，用一套真实考卷证明"识别能力没有变差"。

## 三步

```bash
# 1. 建基线（第一次跑，把当前成绩存下来）
uv run sai eval --save

# 2. 之后任何改动（提示词/模型/路由/粗筛词表）后重跑，自动与基线比对
uv run sai eval

# 3. 若识别对象变了（比如换了官网），清掉旧结论缓存再评测
uv run sai memory clear && uv run sai eval
```

## 判定

- 考卷：31 条真实通知（19 比赛 / 12 杂事，2019-2026），在 tests/fixtures/；
- 差异超过阈值 5pp 判为翻车，逐条点名哪道题从对变错；
- 评测**不使用记忆缓存**——考的是 LLM 的真实判断力，不是缓存命中率。

## 纪律

**改识别相关的一切之后必跑 `sai eval`**：提示词、粗筛词表、模型路由、模型档案。
红了就回退或修到绿再提交——这和"改完代码跑测试"是同一件事。
