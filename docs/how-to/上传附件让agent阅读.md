# 上传附件让 agent 阅读（How-to）

## 步骤

1. 输入卡左下角点 **＋**，选择文件（≤20MB，多个也可以）；
2. 附件以 chip 显示在输入框上方（可点 ✕ 移除）；
3. 发送消息——文件真实上传到 `output/uploads/`，消息里会带 `[已上传: 文件名]`；
4. agent 收到消息后会调用 `read_attachment` 工具读内容，然后回答。

## 支持的格式

| 格式 | 支持 |
| --- | --- |
| .txt / .md / .csv / 代码文件 | 直接读 |
| .pdf | pypdf 提取文字（限 40 页；扫描件提取不到会如实告知） |
| .doc / .docx / .xls / .ppt | 暂不支持——请导出成 PDF 或 Markdown 重传，或直接粘贴文字 |

## 例子

> 上传"参赛要求.txt"后问：我上传的参赛要求里都有什么要求？

agent 会调工具读文件，逐条复述，还能结合库里的真实截止日期给建议。

## 边界

- 单文件内容超 8000 字符会被截断（工具会注明，需要更多可让 agent 分段或你粘贴）；
- agent 读的是**上传时刻**的内容，重传即更新；
- 右侧工具坞（▤）的文件树里也能看到 `uploads/` 目录，配合终端可以手动处理。
