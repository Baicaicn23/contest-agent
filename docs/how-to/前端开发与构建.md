# 前端开发与构建（How-to）

> 前端是 Next.js 15 (App Router) + TypeScript + Tailwind，静态导出由 FastAPI 托管。

## 日常开发

```bash
cd frontend
npm run dev          # 开发服务器 http://localhost:5173
```

注意：`npm run dev` 下页面由 Next 开发服务器提供，**API 请求会 404**——
后端 API 在 8000 端口。两种做法：

- 推荐：改完直接 `npm run build`，然后 `./start.sh`（8000 端口，界面+API 同源）；
- 或者在 next.config.ts 临时加 rewrites 把 `/api`、`/sessions` 等代理到 8000
  （rewrites 在 `output: "export"` 下仅 dev 生效，不影响导出）。

## 构建 + 部署

```bash
cd frontend && npm run build     # 产出 out/（纯静态）
cd .. && ./start.sh              # FastAPI 托管 out/ + API，单端口 8000
# ./start.sh --build              # 强制重新构建
```

## 约定

- 技术栈：TypeScript（strict）+ Tailwind + lucide-react 图标；状态不引库，
  全部在 `lib/app-state.tsx` 的 AppStateProvider（页面切换流式不断线的关键）；
- 会话路由用查询参数 `/chat?session=N`（静态导出不支持动态路由段）；
- 主题只做 snow（纯白+蓝）；颜色一律用语义类（`bg-muted text-muted-foreground`），
  不写死色值；
- 构建产物 `out/` 与 `.next/` 已 gitignore，不要提交；
- typecheck：`npm run typecheck`（strict 模式，build 前自动跑）。
