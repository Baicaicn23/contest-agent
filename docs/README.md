## 四象限速记

- **tutorials/** 教程——学习导向，新手从头跟到尾；
- **how-to/** 指南——任务导向，"我想做 X"一步一查；
- **reference/** 参考——信息导向，精确的事实（字段/端点/命令）；
- **explanation/** 解释——理解导向，为什么这样设计。
