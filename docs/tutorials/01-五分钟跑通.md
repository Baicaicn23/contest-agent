# 教程一：五分钟跑通（Tutorial）

> 目标：从零开始，跑通"扫官网 → 识别比赛 → 看到结果"的最小闭环。
> 前置：装了 Python 3.11+、uv、Node.js，本机可访问学院官网。

## 1. 克隆与安装（约 2 分钟）

```bash
git clone git@github.com:Baicaicn23/contest-agent.git
cd contest-agent
uv sync                       # 后端依赖
cd frontend && npm install && cd ..   # 前端依赖
```

## 2. 配置密钥

```bash
cp .env.example .env          # 如果没有这个文件，直接创建 .env
# 写入一行：
# DEEPSEEK_API_KEY=sk-你的key
```

没有 key？去 platform.deepseek.com 注册充值（识别一场比赛几分钱）。
没有 key 也能跑：纯扫描/日程/界面都可用，只有识别和聊天需要 key。

## 3. 启动

```bash
cd frontend && npm run build && cd ..
./start.sh
```

看到 `Uvicorn running` 就打开了 http://127.0.0.1:8000 ——侧栏、工作台、
"Good morning" 问候都在了。

## 4. 第一场识别

在输入框里输入：

```
/识别
```

回车。约 30 秒后你会看到：扫描了多少条通知、哪些是比赛（证据来自通知原文）、
哪些是杂事被挡下。侧栏"对话"里出现这次任务的轨迹，点开能回放每一步。

## 5. 验证你学会了

- 打开侧栏"日程"：识别出的比赛如果 30 天内截止，会出现在这里；
- 输入 `/账单`：看这次识别花了多少钱（预期几分钱）；
- 打开右侧工具坞（▤）：`output/` 里的产物和通知文件都在。
