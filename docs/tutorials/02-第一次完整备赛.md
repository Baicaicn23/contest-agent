# 教程二：第一次完整备赛（Tutorial）

> 目标：围绕一场真实比赛走完"建项目 → 收材料 → 出 PPT → 防忘"的完整旅程。
> 前置：已完成[教程一](./01-五分钟跑通.md)，库里至少有一张比赛卡片。

## 1. 为比赛建一个项目

侧栏项目树里，比赛卡片已经自动派生成项目（比如"2026第十四届…数字媒体…竞赛"）。
悬停项目行点 **＋**，在该项目下开一个新对话——之后这里的所有问答自动归属到它。

## 2. 让 agent 了解比赛

在对话里直接问：

```
这个比赛的要求和截止日期是什么？
```

agent 会自己调工具查卡片、读通知原文，用表格回答你。（输入卡右下角可以看到
它用的模型；左下角盾牌是权限档，默认"变更前确认"。）

## 3. 生成 PPT 大纲

```
为这场比赛生成 PPT 大纲
```

或输入 `/生成`。约 30-90 秒后，`output/` 里会出现大纲 .md 和 .pptx 文件
（右侧工具坞文件树可见）。

## 4. 上传你的补充材料

点输入卡 **＋**，上传一份你手头的比赛要求文档（txt/md/pdf），然后问：

```
结合我上传的要求，这份大纲还缺什么？
```

agent 会调用读附件工具，把你的要求和它知道的比赛信息合起来回答。

## 5. 打开截止保险

侧栏"通知"铃 → 打开**桌面截止提醒**。当比赛进入 T-7/3/1/0 天警报窗口，
系统会弹通知。（想推到钉钉/邮箱，看 `how-to/配置定时推送.md`。）

## 6. 回顾

侧栏项目树下，这场比赛的所有问答都在；任务型操作（识别/生成）的完整轨迹
在会话回放里，花了多少 token、多少钱，`/账单` 可查。

**你已经用完了核心闭环**：盯 → 识别 → 问答 → 生成 → 提醒。
深入配置看 `../how-to/` 目录。
