# M6 交接计划：界面美化与交互升级（v3 新会话执行）

> **本文档是 v3 会话的完整交接入口。** 新会话恢复方式：读本文件 + `docs/开发文档-v1.md` §12/§13 + 项目记忆（memory/contest-agent-project.md）。执行人不需要读历史对话。

## 一、背景与目标

M4/M5 已把界面复刻到 Claude Desktop + Codex 形态（三视图/项目树/插件市场/聊天 agent），但交互细节粗糙：**点击生硬跳变、无过渡动画、按钮无四态反馈、侧栏贴边、关闭钮位置不统一**。

M6 目标（用户原话拆解）：
1. **每一个按钮、能交互的地方都优化得美观**——全部可交互元素补齐四态（default/hover/active/focus-visible）
2. **加入衔接动画，不要一点击就卡过去**——视图切换、弹层开合、消息入场全部有过渡
3. **侧边栏做成悬浮式的**——脱离贴边，圆角+阴影+与窗口边缘留白
4. **叉叉放在左上角**——所有可关闭面（设置/搜索/通知/工具面板/弹层）的关闭按钮统一移到左上角

## 二、设计规范（源自 ui-ux-pro-max skill 检索，执行时照此实现）

### 动效令牌（新增到 tokens.css）

```css
:root {
  --dur-micro: 120ms;    /* hover/按下等微反馈 */
  --dur-std: 200ms;      /* 弹层开合、视图切换（入） */
  --dur-exit: 150ms;     /* 退出比进入快（非对称，回退才跟手） */
  --ease-out: cubic-bezier(0.2, 0, 0, 1);
  --ease-inout: cubic-bezier(0.4, 0, 0.6, 1);
  --shadow-pop: 既有值保留;
}
```

### 硬规则
- 只动画 `transform` 和 `opacity`（GPU 友好）；**禁止动画 width/height/top/left**
- 退出动画必须比进入快（~250ms 上限），否则应用感觉卡
- `@media (prefers-reduced-motion: reduce)` 下全部动画禁用、直达终态
- 键盘焦点环不可删（focus-visible 保留），含弹层内控件
- 交互最小 44×44px 触达区；图标按钮必须有 title/aria-label
- 界面**禁止 emoji**（用户既定规范）；图标用文字标签或 CSS 形状

## 三、改造清单（按交互元素逐项）

### A. 悬浮侧栏（视觉重头戏）
- 现状：`.sidebar` 贴左边缘、直角、与主区共用边框
- 目标：`position: fixed; top: 12px; left: 12px; bottom: 12px; width: 248px;`
  `border-radius: var(--radius-lg); box-shadow: var(--shadow-pop);` 无右边框
- 主区 `.main` 加 `margin-left: 272px`（= 12 + 248 + 12）补偿
- IconRail 并入侧栏左缘或保留独立悬浮条（同款圆角阴影，二选一在实现时定）
- 入场动画：应用加载时侧栏从 `translateX(-16px)+opacity:0` 滑入（--dur-std）

### B. 关闭按钮统一左上
- 涉及：SettingsPage（现右上 ✕）、SearchOverlay、NotificationsPop、ToolPanel、CustomizePage
- 规格：`.close-btn-tl { position: absolute; top: 14px; left: 14px; }`（图标钮 30×30）
- 全部支持 Esc 关闭（SettingsPage 已有，其余补齐）
- 弹层开合动画：`opacity 0→1 + scale 0.96→1`（--dur-std + --ease-out）；关闭直接卸载（退出 150ms 可选）

### C. 全部可交互元素四态清单（逐个过）
| 元素 | hover | active（按压） | focus-visible |
| --- | --- | --- | --- |
| rail-btn / side-item / session-item | 背景色 120ms 过渡 | scale(0.97) | 焦点环 2px accent |
| pill-btn（chips/自动入库） | 边框变 accent + 微升 | scale(0.96) | 同上 |
| send-btn | 加深 + scale(1.05) | scale(0.94) | 焦点环 |
| toggle（设置开关） | — | knob 滑动 150ms 弹性 | 焦点环 |
| plugin-add / idea-row / cmd-item | 背景色 | scale(0.98) | 焦点环 |
| model-pill / icon-btn / tab | 背景色 | scale(0.97) | 焦点环 |

### D. 衔接动画（"不要一点击就卡过去"）
- **视图切换**（rail 导航/标签切换）：主区内容 `opacity 0→1`（--dur-std），
  旧内容退出 --dur-exit；实现用 CSS animation 类 + key 换触发，不引路由库
- **弹层**（搜索/通知/项目 popover/命令面板）：淡入 + 轻微上移（translateY 4px→0）
- **消息入场**：新消息 `translateY(8px)+opacity 0→1`（120ms）；流式增量不动画（只在追加整条时）
- **标签页**：active 指示用滑动下划线/背景（transition background+transform）
- **侧栏项目树**：子行展开/收起用 max-height 或 grid-template-rows 过渡（200ms）

### E. 明确不做
动态第三方插件、移动端适配、登录体系、语音/Mini 宠物等无能力占位项保持现状

## 七、风险与提醒

- 过渡动画加在 `.main` 全局可能拖慢聊天流式渲染——只加在挂载/卸载类名上，不给流式文本节点加
- 侧栏悬浮化后 `.main` 布局补偿要同步改，否则出现横向滚动
- ChatView 的 key 切换会整体重挂——入动画用 CSS animation 类（挂载自动播），避免 JS 控制闪烁
