# 配置参考（Reference）

> config.yaml 的全部字段。环境变量优先于本文件（密钥只写"环境变量名"，绝不写明文）。

## 顶层

| 字段 | 说明 | 默认 |
| --- | --- | --- |
| `active_model` | 当前生效的模型档案名（models 的键） | `deepseek` |
| `budget_per_task_yuan` | 单任务 LLM 花费上限，达线熔断；null 不限 | `null` |
| `access_full` | 完全访问总闸（true = 权限门全放行）；由 permission_mode=full 同步 | `false` |
| `context.trigger_ratio` | agent 上下文占用达模型窗口该比例时触发压缩 | `0.8` |
| `features` | 能力插件开关：`deadlines` / `watch` / `eval` / `pptx` | 全 true |
| `sources` | 官网源列表（name/base_url/list_path/detail_pattern/request_interval/selectors） | 至少一个 |

## models（模型档案）

键是档案名（routing 和 active_model 引用它）：

```yaml
models:
  deepseek:
    base_url: https://api.deepseek.com   # OpenAI 兼容端点
    api_key_env: DEEPSEek_API_KEY        # 密钥的环境变量名（值放 .env）
    model: deepseek-flash                # 服务商的模型 ID
    input_price_per_m: 2.0               # 计费单价（元/百万 token），台账算钱用
    output_price_per_m: 8.0
```

## routing（按任务路由模型）

键是任务名（identify / generate / study_path / chat…），值是档案名；
没列出的任务用 active_model 兜底。台账可查证每个任务实际用了谁。

## permissions（权限门，M9 三档）

| 字段 | 说明 |
| --- | --- |
| `permission_mode` | **三档权限**：`readonly`（写类工具一律拒绝）/ `confirm`（写类执行前确认；网页聊天无法弹窗会自动拦截）/ `full`（全放行，同步 access_full=true）。前端输入卡可切 |
| `confirm_tools` | 终端交互时执行前要 y/N 的工具名 |
| `unattended_deny_tools` | 无人值守（cron/服务）时一律拒绝的工具名 |

写类工具名单在 `application/harness/permission_gate.py` 的 `WRITE_TOOL_NAMES`
（scan_latest_notices / identify_latest_notices / save_material）。

## push（推送通道，三通道独立）

```yaml
push:
  webhook_url: null          # 钉钉/企微/Server酱 的机器人地址；配了即启用
  webhook_timeout: 10
  file_dir: output/notifications   # 通知写 Markdown 到本地目录
  smtp:                      # 邮件通道（密码走 SMTP_PASSWORD 环境变量）
    host / port / user / to_addrs
```

## 密钥环境变量（.env，已被 gitignore）

| 变量 | 用途 |
| --- | --- |
| `DEEPSEEK_API_KEY` | DeepSeek 档案 |
| `DASHSCOPE_API_KEY` | 通义千问档案 |
| `SMTP_PASSWORD` | 邮件推送 |
| `ACTIVE_MODEL` / `BUDGET_PER_TASK_YUAN` | 临时覆盖 yaml（实验用） |
