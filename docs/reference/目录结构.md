# 目录结构（Reference）

```
contest-agent/
├── app/                        # 前端（Next.js App Router 路由）
│   ├── page.tsx                #   / 工作台（serif 问候 + 输入卡）
│   ├── chat/                   #   /chat 会话页（?session=N）
│   ├── stats/ deadlines/       #   统计 / 截止日程
│   ├── plugins/ settings/      #   插件市场 / 设置
│   └── globals.css             #   主题令牌（snow）
├── components/                 # 前端组件（app-shell/sidebar/chat-composer/message-list）
├── lib/                        # 前端库（api/app-state 全局状态/markdown/types/format）
├── out/                        # next build 静态导出产物（gitignore）
├── src/contest_agent/
│   ├── domain/                 # 实体 + 端口（Protocol）——最内层
│   ├── application/
│   │   ├── usecases/           # 业务用例（scan/identify/generate/study_path/chat…）
│   │   ├── harness/            # AgentScope 装配/权限门
│   │   └── cost.py             # 计价器
│   ├── infrastructure/         # 端口实现（SQLite/LLM/爬虫/推送）
│   ├── presentation/           # server.py（HTTP）+ cli.py（sai 命令）
│   ├── composition.py          # 装配根（依赖注入）
│   └── settings.py             # 配置读取（env > config.yaml）
├── skills/                     # 技能提示词（ppt-outline 等，frontmatter 描述）
├── tests/                      # pytest（178 离线 + 4 live）
├── docs/                       # 本文档体系（Diátaxis 四象限）
├── config.yaml                 # 主配置（模型/路由/权限/推送/源选择器）
├── data/                       # SQLite 库（gitignore）
├── output/                     # 生成产物（材料/通知/上传附件）
└── frontend/                   # ↑ 上面 app/components/lib 的容器（Next.js 项目根）
```

## 关键文件速查

| 想改什么 | 去哪 |
| --- | --- |
| 加一个官网源 | config.yaml `sources`（选择器配置化，不用改代码） |
| 加/改 HTTP 端点 | presentation/server.py |
| 加 sai 子命令 | presentation/cli.py |
| 改识别提示词/粗筛 | application/usecases/identify_competitions.py |
| 改聊天工具 | application/harness/agent_factory.py（build_chat_tools） |
| 加写类工具到只读黑名单 | application/harness/permission_gate.py（WRITE_TOOL_NAMES） |
| 改主题颜色 | frontend/app/globals.css 的 CSS 变量 |
