# 架构总览（Reference）

> 本文是精确的架构参考：分层规则、模块地图、一次请求的数据流。
> 想知道"为什么这样设计"，看 `explanation/设计决策.md` 和 ADR。

## 技术栈

| 层 | 技术 |
| --- | --- |
| 后端 | Python 3.11 + FastAPI + SQLAlchemy/SQLite + AgentScope 2.0.8 + uv |
| 前端 | Next.js 15 (App Router) + TypeScript + Tailwind + lucide-react，静态导出 out/ |
| LLM | DeepSeek 为主（OpenAI 兼容协议，多档案可切换） |

## 分层（DDD 洋葱模型）

依赖只能**从外向内**，内层不知道外层的存在：

```
presentation/   ← FastAPI 路由 + CLI（把外部世界翻译成用例调用）
application/    ← 用例（业务编排）+ harness（AgentScope 接驳/权限门/工具链）
domain/         ← 实体 + 端口（Protocol 接口）——最内层，零外部依赖
infrastructure/ ← 端口实现（SQLite 仓储 / OpenAI 兼容 LLM / 爬虫 / 推送）
composition.py  ← 装配根：把所有实现注入用例（类比 Spring 的容器配置）
```

类比 Java：domain 的 Port = interface，infrastructure = @Repository/@Service 实现，
composition = @Configuration，presentation = @Controller。

## 模块地图（src/contest_agent/）

```
domain/
  entities.py        # Competition / Notice / UsageEntry / SessionSummary / ProjectInfo…
  ports.py           # 全部 Protocol：抓取/LLM/记忆/会话存档/推送/项目存储…
application/
  usecases/          # scan_site / identify_competitions / generate_material /
                     # study_path / chat_service / deadline_watch / workspace …
  cost.py            # CostMeter 计价器（precheck 熔断 + record 记账）
  harness/
    agent_factory.py # AgentScope 装配：模型/工具链/聊天流式胶水/计价代理
    permission_gate.py # 三档权限门 + WRITE_TOOL_NAMES
infrastructure/
  llm/openai_compat.py    # OpenAI 兼容 LLM（结构化调用 + 计价注入）
  crawler/                # 官网抓取（选择器配置化）
  persistence/repository.py  # SQLite 仓储（ competitions/notices/sessions/usage/projects/memories）
  push/                   # webhook / 邮件 / 文件 三通道
presentation/
  server.py          # 全部 HTTP 端点（见 API 参考）
  cli.py             # sai 命令族（见 CLI 参考）
```

## 一次聊天请求的数据流

```
浏览器 POST /api/chat（SSE）
  → ChatService.stream_reply          # 人设 + 6 轮历史 + 轨迹留档
    → run_chat_agent_stream           # harness 胶水：AgentScope ReAct 循环
      → MeteredChatModel              # 预算 precheck → 调模型 → usage 记账
        → DeepSeekChatModel(stream=)  # 真流式，逐字 TextBlockDeltaEvent
      → Toolkit（七件工具，权限门已套壳）  # 查卡片/读通知/搜索/截止/扫官网/识别/读附件
  ← SSE 帧：session → token* → tool* → done
```

前端侧：`lib/app-state.tsx` 的 AppStateProvider 持有运行时状态——
**工作台发送后路由切到 /chat，SSE 流在 Provider 里继续，跨页面不断线**。

## 前端结构（frontend/，Next.js 静态导出）

```
app/          # 路由：/ 工作台 · /chat · /stats · /deadlines · /plugins · /settings
components/   # app-shell（侧栏+主区）/ sidebar / chat-composer / message-list
lib/          # api（API 客户端）/ app-state（全局状态 Context）/ markdown / types / format
```

- `output: "export"` 静态导出到 `out/`，由 FastAPI StaticFiles 托管（单端口部署）；
- 会话路由用查询参数 `/chat?session=N`（静态导出不支持动态路由段）；
- 全局状态模式沿袭 TeachX 的 ChatStateAdapter：运行时状态收进 Provider，
  页面切换不卸载，SSE 流跨页面不断线。
