### 已确认的决策（两轮拷问）
1. **React + Vite + JavaScript**（不用 TS，先学 React 本身）
2. **中文本地化**：布局/配色/组件像素级复刻，文案换中文（"接下来做什么，momo？""你来了！""自动入库"）

4. **Settings 真实读写子集**：可写 = 切模型档案 + 预算上限（按行替换保 yaml 注释）；只读 = 路由表/权限名单/推送通道/档案列表
5. **手写 CSS + 设计令牌**（tokens.css 集中管理颜色/圆角/字体，不引 Tailwind/组件库）
6. 我定的执行细节：不引 react-router（AppShell 内状态切换视图）、不引状态库（useState/useContext）、npm、FastAPI 托管 frontend/dist、chat 带同会话最近 6 轮上下文、chat 人设="比赛情报助手"（系统提示注入实时数据：卡片数/今日花费）
