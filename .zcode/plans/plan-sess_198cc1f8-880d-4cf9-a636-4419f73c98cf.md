## M5：复刻 Codex 桌面版——布局重构 + 全部按钮接真后端

### 已确认决策
- **项目 = 按比赛自动成项目**：每张识别出的卡片自动成为一个项目，聊天/材料可归属；支持手动新建
- **插件市场 = 能力开关映射**：插件 = 系统能力（截止守望/评测/盯梢/pptx 导出/邮件/webhook/预算闸门…），安装 = 写 config 开关，未装则对应接口降级 503
- 我定的执行细节：布局外壳**完全替换**为 Codex 式（图标栏+项目树侧栏+标签页+chips+全页设置+插件页），现有真实数据组件（Overview 卡/聊天/回放/命令面板）全部迁入保留；不引入路由库，多标签用状态管理；截图里的语音/Mini 宠物/电脑操控等无对应能力的项做视觉占位

### 后端新增（一次提交，全部带测试）
1. **projects 表**（id/name/source auto|manual/card_url_hash）+ sessions 幂等加 project_id 列（沿小型迁移先例）+ 端点：`GET /api/projects`（卡片自动派生+手动）、`POST /api/projects`（手动建）、`POST /api/projects/bind`（会话归属）
2. `GET /api/search?q=`：会话备注 + 卡片名 + 通知标题 LIKE 搜索
3. `GET /api/skills`：解析 skills/*.md frontmatter（名称/描述）
4. `GET /api/git/branch`：subprocess 读当前分支（composer 的 main chip）
5. `GET /api/files`：output/ 真实文件列表（右侧工具面板）
6. `GET /api/notifications`：截止 urgent 数 + 近期完成会话（铃铛下拉）
7. **插件体系**：config 新增 `features:` 段（eval/deadlines/watch/pptx/smtp/webhook 布尔开关，行级读写保注释）+ `GET /api/plugins`（能力清单+enabled+分类）+ `POST /api/plugins/{id}/toggle`；未启用的能力对应接口降级（deadlines/eval 先接）
8. `POST /api/config/access`（完全访问开关 → 写 permissions：开=清空 unattended_deny+confirm，关=恢复名单）+ `GET /api/git/branch`
